# Crèdits lingüístics

CoCoPress utilitza [Stanza](https://stanfordnlp.github.io/stanza/) per a la
tokenització, la lematització i l'etiquetatge POS.

Les etiquetes POS són UPOS de
[Universal Dependencies](https://universaldependencies.org/). Els textos
etiquetats segueixen el format `paraula_POS_lemma`.
